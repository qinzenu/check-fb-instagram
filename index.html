    Tentang Website

    Apa itu ZN-Tools?

    Kumpulan tools web yang praktis, ringan, dan menjaga privasimu. Saat ini tersedia Cek Follback Instagram.

    ZN-Tools dibuat untuk membantu pekerjaan kecil sehari-hari terasa lebih cepat dan sederhana. Setiap tool punya satu tujuan yang jelas, tampilan yang bersih, dan cara pakai yang mudah dipahami, baik dari HP maupun komputer.

    Tool pertama, Cek Follback Instagram, membantu kamu melihat siapa saja yang tidak follback hanya dari data ekspor resmi Instagram milikmu sendiri.

    Fitur

    Yang bisa kamu lakukan

    Semua analisis dilakukan dalam hitungan detik setelah file kamu dipilih.

    Unggah data ekspor

    Pilih file .zip dari Instagram, atau file followers_1.json dan following.json. Bisa juga diseret langsung ke kotak unggah.

    Ringkasan akun

    Lihat jumlah followers, following, akun yang tidak follback, dan akun yang saling follow dalam satu tampilan.

    Daftar & pencarian

    Pindah antar tab hasil, lalu cari username tertentu dengan cepat tanpa menggulir daftar yang panjang.

    Salin & unduh CSV

    Salin daftar username atau simpan sebagai CSV, dan buka profil akun langsung dari hasil.

    Cara kerja

    Tiga langkah sederhana

    1. Ekspor data dari Instagram

      Minta salinan informasimu lewat pengaturan Instagram dalam format JSON. Panduan lengkapnya tersedia di halaman Cek Follback.

    2. Unggah file ke ZN-Tools

      Pilih file hasil ekspor. Jumlah akun di setiap file langsung ditampilkan sebagai konfirmasi.

    3. Lihat hasilnya

      Tekan Cek Sekarang dan tunggu proses selesai. Hasil muncul beserta daftar yang bisa dicari, disalin, atau diunduh.

    FAQ

    Pertanyaan yang sering diajukan

    Apakah file saya diunggah ke server?
    Tidak. File dibaca dan dianalisis langsung di browser pada perangkatmu. Proses ini tidak mengunggah file ke server mana pun.
    Apakah saya perlu login atau memberikan kata sandi Instagram?
    Tidak perlu. ZN-Tools hanya membaca file ekspor yang kamu pilih sendiri, jadi tidak ada akun atau kata sandi yang diminta.
    File apa saja yang didukung?
    File .zip hasil ekspor Instagram, atau file JSON followers_1.json dan following.json. Kalau followers kamu banyak, tambahkan juga file followers lainnya yang ikut terunduh.
    Apakah ZN-Tools berafiliasi dengan Instagram?
    Tidak. ZN-Tools adalah proyek independen dan tidak berafiliasi, disponsori, atau didukung oleh Instagram maupun Meta.

    Langkah-langkah

    1. Siapkan file hasil ekspor data Instagram: satu file .zip, atau followers_1.json dan following.json. Belum punya? Lihat panduan Cara mendapatkan file JSON dari Instagram di bawah tombol Cek Sekarang.
    2. Ketuk kotak Ketuk untuk memilih file atau seret ke sini, lalu pilih file dari folder Download.
    3. File yang dipilih muncul di daftar beserta jumlah akunnya. Ketuk Tambah file lain jika masih kurang, atau ketuk ✕ untuk membuang satu file.
    4. Klik tombol Cek Sekarang dan tunggu analisis sampai 100%.
    5. Lihat Ringkasan Akun: jumlah Followers, Following, Tidak Follback, dan Saling Follow. Ketuk Lihat semua untuk melihat seluruh daftar followers atau following.
    6. Pindah antar tab untuk melihat daftarnya: Tidak Follback (kamu follow, tapi dia tidak follow balik), Belum Kamu Follback (dia follow kamu, tapi kamu belum follow balik), dan Saling Follow.
    7. Ketik username di kolom Cari username untuk mencari akun tertentu.
    8. Ketuk Salin untuk menyalin daftar username, atau CSV untuk mengunduh daftarnya.
    9. Ketuk Buka di samping akun untuk membuka profilnya di Instagram.

    Langkah-langkah

    1. Buka aplikasi Instagram, masuk ke Profil, lalu ketuk ikon menu ☰ di kanan atas.
    2. Pada Pengaturan dan aktivitas, pilih Pusat Akun.
    3. Pilih Informasi dan izin Anda.
    4. Pilih Ekspor informasi Anda. Halaman akan terbuka di browser.
    5. Ketuk Buat ekspor.
    6. Pilih akun Instagram yang ingin dicek.
    7. Pada Pilih tempat untuk mengekspor, pilih Ekspor ke perangkat.
    8. Pada Pilih info tertentu untuk diekspor, ketuk Hapus semua, lalu scroll ke bagian Koneksi dan centang Pengikut dan mengikuti. Ketuk Simpan.
    9. Pada halaman Konfirmasikan ekspor Anda, ketuk Rentang tanggal, pilih Sepanjang waktu, lalu Simpan.
    10. Ketuk Format, ubah dari HTML menjadi JSON, lalu Simpan.
    11. Ketuk Kualitas media, pilih Kualitas lebih rendah, lalu Simpan.
    12. Ketuk Mulai ekspor, lalu masukkan kata sandi Instagram jika diminta dan ketuk Lanjutkan.
    13. Tunggu beberapa menit sampai ekspor selesai. Statusnya muncul sebagai Diminta, lalu berubah menjadi Unduhan yang tersedia.
    14. Ketuk Unduh, lalu ketuk Download di halaman Unduh file Anda. Masukkan kata sandi lagi jika diminta.
    15. Jika muncul pesan Anda keluar dari aplikasi kami, ketuk Lanjutkan. File .zip akan terunduh di browser.
    16. Pastikan file berformat .zip dan berisi followers_1.json serta following.json.
